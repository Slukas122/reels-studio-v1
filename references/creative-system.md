# Creative system for a Reel

Use this when the brief is open-ended or when a repeatable brand style is needed. Do not force the template onto a tightly specified request.

## Compact brief

Record only decisions that affect production:

| Field | Decision |
|---|---|
| Audience and one job | What should the viewer understand, feel or do? |
| Source of truth | Footage, photo, product page, data, script, approved brand file |
| One message | A sentence the finished Reel can actually prove or express |
| Supporting ideas | Subpoints that make the message understandable, each tied to a source range or verified fact |
| Hook and payoff | First visible or audible idea; final resolved idea |
| Fixed text and claims | Exact spelling, names, numbers, caveats and source |
| Format | Each target platform and placement, aspect ratio, length, language, silent-viewing needs |
| Interface | Current top navigation, right-side actions, bottom profile/description and other controls per placement; one shared export or tailored variants |
| Identity | Colors, fonts, logo, contrast, caption treatment, reference |
| Audio | Speech priority, music source or style, SFX, usage rights |

If the user asks for a series, first make a reusable brand sheet in the job files. A new profile needs explicit or supplied evidence. Record which choices are approved and which are inferred. Reuse stable elements, while changing hook, shot design and pacing according to the content.

## Timed beat sheet

For each beat write `time · visual evidence/scene · exact visible text · audio · motion/cut · viewer takeaway`. Aim for a clear opening, sufficient context, one main demonstration or progression, and a resolved ending. A CTA appears only if requested or naturally required by the brief. Do not pad to a target duration.

The opening should make a specific promise the rest of the video fulfills. Record the exact beat that pays it off. Visual novelty alone is insufficient. Deliver the default single-frame cover and standalone thumbnail described in SKILL.md. After that frame, a footage-led Reel opens with the strongest true image or spoken line; a longer title intro is optional only when the brief calls for it. For educational Reels, show the thing being explained. For product Reels, keep the product identifiable and labels accurate. For spoken clips, preserve the speaker's intent and causal order. Use [story-and-formats.md](story-and-formats.md) to decide whether a continuous excerpt, editorial Q&A, demonstration, reportage, hybrid or motion-only sequence best carries the message.

## Review rubric

Use these as diagnostic questions rather than a mechanical score target:

1. Can a new viewer understand the point and reason to continue in the opening?
2. Does each shot advance meaning or give needed breathing room?
3. Are words, numbers, faces, products and UI legible at phone size?
   Check key content under a representative overlay of the target app, including longer descriptions when relevant.
   Measure every text component and check its longest copy with [text-fit.md](text-fit.md).
4. Do movement and cuts help comprehension, with no accidental blank frames or jitter?
5. Are speech, music and effects balanced and clean at each transition?
6. Are all claims supported by the brief, source footage or checked data?
7. Does the ending resolve the idea without trailing into another sentence?

Fix the most important observed defect, preview the affected interval again, then check the final file. Do not iterate merely to reach a prescribed number of passes.
