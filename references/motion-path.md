# Code-rendered motion path

Use for a Reel composed mainly from typography, shapes, photos, data or real website screenshots, including a silent explainer or advertisement with no filmed speaker. Read [story-and-formats.md](story-and-formats.md) first: write one supported proposition, its necessary subpoints and a visual payoff. Read the sibling skill at `../../motion-studio/SKILL.md` and the chosen style file. Start from its matching functional example; copy the engine and relevant assets into a new job directory. Keep the installed skill unchanged. Run its setup only if the runtime is absent.

## Adapt Motion Studio to the brief

Choose the visual mode, ratio, duration, palette and music from the user's brief first. If unspecified, infer them from audience, platform and assets; use [default-brand.md](default-brand.md) when no client identity exists. For an energetic intro, the 01 kinetic showreel example is a strong starting point: borrow its clear hierarchy, contrast, rhythm and purposeful technique changes, not its exact colors or copy. Follow [minimal-rhythm.md](minimal-rhythm.md) so visual energy comes from timing and transformation rather than stacked decoration. A 9:16 format is the default for Reels, but recompute composition for the requested ratio rather than cropping a mismatched template. Motion Studio's current documented range is 6–30 seconds; use another workflow for longer videos. Do not add synthetic speech merely because there is no source audio. A motion-only piece must communicate through visual copy and progression with sound off.

For a website, capture the real interface with `capture.mjs` and inspect the screenshots before animating. For supplied photos, inspect composition and keep the subject visible under overlays. Extract colors from supplied brand assets when useful. For factual explainers or graphs, verify source numbers; visibly label sample data. For user music, derive beat timing with `beats.py` and render with `--track`; otherwise use a fitting synthesized style or effects only. Record the license of external music.

Create or update a timed beat sheet before editing the HTML example. For an ad, show the actual product, offer or demonstrated benefit before an optional relevant CTA; verify every claim. Implement visuals as a deterministic function of time through `window.seek(t)`. Use the engine's springs and tracks for movement, seeded random functions for texture, and declared fonts and images. Avoid CSS animation, timers or mutable frame-to-frame state in a render. Follow [text-fit.md](text-fit.md) for each title, number and card; measure final text rather than trusting template placeholders. Plan headings, chapter labels, credits and progress UI against each target placement's interface from [platform-safe-zones.md](platform-safe-zones.md); inherited example coordinates are not evidence of platform safety. Use full-bleed imagery where it helps, while protecting the actual essential subject and text.

Run `node render.mjs film.html --stills` and inspect the contact sheet plus phone view. Inspect short intervals around fast transitions with smaller `--every` values when needed. Correct blank frames, clipping, unreadable text, unmotivated motion and weak end frames. Then render the final MP4, decode or probe it with FFmpeg, and watch it with sound from start to end. Motion Studio can export separate music and effects stems; deliver them only when useful.

If a motion section must sit inside an existing-footage Reel, render that section as a self-contained clip with the target resolution, frame rate and timing. Assemble it with the footage in the reels-editor timeline and validate the **assembled** result. The canvas engine's full-frame video is not automatically a transparent overlay.
