# Reels Studio V1

Původní verze skillu Reels Studio pro tvorbu krátkých videí z dodaných záběrů a grafiky.

Tato publikace obsahuje nezměněné soubory zálohy `pre-v2-2026-10-05` (commit `eac4164`) pořízené před vývojem V2. Přidán je pouze tento README. Neobsahuje V2/V3, osobní brand manuál, fotografie ani referenční videa.

## Použití

Umístěte obsah tohoto repozitáře do složky skillu `reels-studio` v prostředí podporujícím `SKILL.md`. Například v Codexu do `~/.codex/skills/reels-studio`. Existující instalaci nejprve zálohujte, pokud si chcete zachovat novější verzi.

Skill vyvolejte jako `$reels-studio` a přiložte zdrojová videa a požadovaný výsledek.

## Závislosti a rozsah

Jde o instrukční a koordinační skill, nikoli samostatný editor videa. Původní V1 směruje střih do sourozeneckého skillu `reels-editor` a motion grafiku do `motion-studio`. Tyto dva skilly nejsou součástí tohoto repozitáře a musí být dostupné zvlášť pro příslušnou produkční cestu. Samotné stažení tohoto repozitáře nezajišťuje celý renderovací nástrojový řetězec.

Součástí jsou původní reference, instrukce a pomocné Python skripty. Osobní nastavení autora nejsou přibalena.
